# Reproducibility checklist

Each item states what was done and where the evidence lives. Items that were
**not** achieved are listed as such rather than omitted.

| Item | Status | Evidence |
|---|---|---|

## Not achieved, and stated as such

| Item | Status | Note |
|---|---|---|
| Scopus / Embase literature search | **No** | Not accessible in the development environment. Novelty statements are phrased "we identified no study that…", naming the databases searched. |
| Survey-weighted parallel analysis | **No** | No established implementation exists. Used as a heuristic with the over-retention bias stated, supported by scree inspection, an effective-*n* robustness run, and prior interpretability. |
| Non-differential measurement error | **No** | Contradicted by our own data: implausible reporters had higher BMI and higher apparent diet quality. The calibration is therefore partial and conservative. |
| Measurement-error correction of substitution estimates | **No** | Would require multivariate calibration across 17 groups; not attempted. Substitution estimates are attenuated lower bounds. |
| Cycle-contemporaneous FNDDS assignment | **No** | The pre-pandemic public file omits the survey-cycle identifier for disclosure control, forcing one classification per food code. |
| MetS severity score across all groups | **No** | Published coefficients do not exist for non-Hispanic Asian or Other/Multiracial participants. |
| Pre-registration on a public registry | **No** | The protocol was frozen and version-controlled, but not deposited in an external registry. |
| Byte-identical **figure** reproduction confirmed on a second machine | **No** | The cause of the earlier failure is fixed and tested (Amendment 9), and figure reproduction is now Partial rather than No in *Computation* above. It is listed here too because the confirming test — a clean-clone rebuild on a second machine *since* the fix — has not been run. Claiming it on same-machine evidence is the specific error Amendment 8 corrected. |

## How to reproduce

```bash
git clone https://github.com/ImmunoScholar/nhanes-pbdi-cardiometabolic.git
cd nhanes-pbdi-cardiometabolic
R -e 'renv::restore(prompt = FALSE)'
make all       # rebuild everything from public source data
make verify    # rebuild from clean and confirm artefact checksums are identical
```

Expected runtime is approximately 30 minutes, dominated by multiple imputation
(m = 20, 20 iterations) and two replicate bootstraps of 500 replicates each.
